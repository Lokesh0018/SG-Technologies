# SG Technologies

A modern, dynamic web application for SG Technologies, built with React, Vite, Three.js, and GSAP. This project features immersive 3D graphics and smooth animations to provide a premium user experience.

## Technologies Used

- **React 19**
- **Vite** - Next Generation Frontend Tooling
- **Three.js & React Three Fiber** - For 3D rendering and components
- **GSAP** - Professional-grade animations
- **React Router DOM** - For client-side routing

## Initialization Steps

Follow these steps to set up and run the project locally:

1. **Install dependencies**:
   Make sure you have Node.js installed, then run:
   ```bash
   npm install
   ```

2. **Start the development server**:
   ```bash
   npm run dev
   ```
   The application will be available at `http://localhost:5173` (or the port specified by Vite in your terminal).

3. **Build for production**:
   To create a production-ready build, run:
   ```bash
   npm run build
   ```

4. **Preview the production build**:
   ```bash
   npm run preview
   ```
